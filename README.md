# BiteBook graphics

Finished social graphics, copied into Google Drive (City > Ready to Post) by Zapier. Not part of the website.

## Making images
`node _tools/render.js _tools/fonts <outDir> <file.dc.html>...` renders Design canvas artboards to PNG at their exact size with the brand fonts (OFL licensed).
Folders: `<city>/<event>/<name>.png`. Each file is then copied to Drive (BiteBook > City > event folder > Ready to Post) with Zapier's Google Drive "Upload File" using its raw.githubusercontent.com link.
